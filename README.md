# Potatura

**IT** — Potatura ti aiuta a ripulire con calma l'elenco degli account che segui su Instagram, partendo dall'export
ufficiale dei tuoi dati. Gira solo sul tuo computer: nessun server, nessuna password salvata.

- **Scarica l'ultima versione per Windows:** [Releases → Latest](https://github.com/RoadToRoad/potatura-releases/releases/latest)
  (file `Potatura-Setup-<versione>.exe`).
- Al primo avvio Windows può mostrare "Windows ha protetto il PC" (l'installer non è firmato): *Ulteriori
  informazioni* → *Esegui comunque*.
- Le copie installate controllano da sole gli aggiornamenti e propongono **Installa e riavvia**.
- [Informativa sulla privacy](PRIVACY.md)

**EN** — Potatura helps you calmly clean up the list of accounts you follow on Instagram, starting from your official
data export. It runs only on your computer: no servers, no stored passwords.

- **Download the latest Windows version:** [Releases → Latest](https://github.com/RoadToRoad/potatura-releases/releases/latest)
  (`Potatura-Setup-<version>.exe`).
- On first run Windows may show "Windows protected your PC" (the installer is not signed): *More info* → *Run anyway*.
- Installed copies check for updates by themselves and offer **Install and restart**.
- [Privacy policy](PRIVACY.md)

Potatura non è affiliato a Instagram né a Meta. / Potatura is not affiliated with Instagram or Meta.
